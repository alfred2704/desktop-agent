## 💡 使用示例

### 简单操作（规则匹配）

```python
from layers.layer1_intent.enhanced_intent_parser import EnhancedIntentParser

parser = EnhancedIntentParser(config)

# 基础操作
parser.parse("点击确定按钮")  # → {"intent": "click", "confidence": 0.95}
parser.parse("在搜索框输入'Python'")  # → {"intent": "type", ...}
parser.parse("按Ctrl+S")  # → {"intent": "hotkey", ...}

# 扩展操作
parser.parse("点击第3个按钮")  # → {"intent": "click_index", "index": 3}
parser.parse("重复点击5次")  # → {"intent": "loop_times", "times": 5}
parser.parse("如果确定按钮存在就点击")  # → {"intent": "if_exists", ...}
```

### 复杂操作（AI理解）

```python
# AI理解
parser.parse("点击那个红色的按钮")  # → AI识别颜色+目标
parser.parse("把刚才复制的内容粘贴到这里")  # → AI理解上下文
parser.parse("如果价格小于100就购买")  # → AI理解条件
```

### 交互确认

```python
# 需要确认
result = parser.parse("点击按钮")  # 目标不明确

if result.get("needs_confirmation"):
    print(result["question"])  # "请选择要操作的目标："
    print(result["options"])  # [确定按钮, 取消按钮, ...]
```
