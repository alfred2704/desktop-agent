## 🔍 详细优化内容

### 1. Few-shot示例优化

**优化前：**
- 示例数量：0个
- AI需要自己理解格式
- 输出不稳定

**优化后：**
- 示例数量：6个
- 覆盖从简单到复杂
- 输出格式一致

**示例结构：**
```
示例1：简单点击（1步）
示例2：输入操作（1步）
示例3：快捷键（2步）
示例4：文档工作流（3步）
示例5：数据处理（3步）
示例6：跨应用（4步）
```

**预期提升：**
- 格式一致性：+20%
- 参数提取准确率：+15%
- 理解准确率：+7%

---

### 2. 结构化分析指南

**优化前：**
```
简单提示：
"识别所有步骤，理解关系"
```

**优化后：**
```
6步详细分析：
1. 识别所有步骤（不遗漏）
2. 理解步骤依赖关系
3. 识别涉及软件
4. 提取所有参数
5. 评估风险
6. 设计数据流
```

**预期提升：**
- 步骤完整性：+25%
- 依赖关系准确率：+30%
- 参数提取率：+20%

---

### 3. 错误模式识别

**优化前：**
- 无错误模式指导
- AI容易犯常见错误

**优化后：**
```
4种常见错误模式：
❌ 错误1：遗漏步骤
   解决：明确列出所有步骤

❌ 错误2：依赖关系不明确
   解决：在data_flow中明确

❌ 错误3：风险识别不足
   解决：risks字段必填

❌ 错误4：参数不准确
   解决：提供参数类型示例
```

**预期提升：**
- 错误率降低：-30%
- 风险识别率：+40%

---

### 4. 输出格式规范

**优化前：**
```
简单的JSON格式要求
容易格式错误
```

**优化后：**
```
5条格式要求：
1. 严格的JSON格式
2. 不要注释或说明文字
3. 确保引号和逗号正确
4. 检查JSON有效性
5. 字段名称与示例一致
```

**预期提升：**
- JSON解析成功率：+15%
- 格式错误率：-50%
