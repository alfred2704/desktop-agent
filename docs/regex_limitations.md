# 正则表达式扩展建议

## 🔴 当前缺失的操作类型

### 1. 条件判断
```python
"condition": [
    r"如果\s*(.+?)\s*[,，]?\s*就\s*(.+)",           # 如果A1>100，就保存
    r"若\s*(.+?)\s*[,，]?\s*则\s*(.+)",             # 若文件存在，则打开
    r"当\s*(.+?)\s*时\s*[,，]?\s*(.+)",             # 当加载完成时，点击
]
```

### 2. 循环操作
```python
"loop": [
    r"从\s*(\d+)\s*到\s*(\d+)\s*[,，]?\s*(.+)",     # 从1到10，点击
    r"重复\s*(\d+)\s*次\s*(.+)",                    # 重复5次点击
    r"依次\s*(.+)",                                 # 依次点击这三个按钮
    r"遍历\s*(.+?)\s*[,，]?\s*(.+)",                # 遍历所有文件，删除
]
```

### 3. 变量操作
```python
"variable": [
    r"把\s*(.+?)\s*保存为\s*(.+)",                  # 把结果保存为变量A
    r"读取\s*(.+?)\s*的值",                         # 读取A1的值
    r"将\s*(.+?)\s*赋值给\s*(.+)",                  # 将100赋值给变量X
]
```

### 4. 数据提取
```python
"extract": [
    r"提取\s*(.+?)\s*的\s*(.+)",                    # 提取表格的第一列
    r"获取\s*(.+?)\s*的值",                         # 获取价格
    r"读取\s*(.+?)\s*中的\s*(.+)",                  # 读取Excel中的数据
]
```

### 5. 相对定位
```python
"relative_position": [
    r"第\s*(\d+)\s*行\s*第\s*(\d+)\s*列",           # 第3行第5列
    r"(?:左边|右边|上面|下面)\s*的\s*(.+)",         # 下面的按钮
    r"(?:第一个|第二个|第三个|最后)\s*(.+)",        # 第一个文件
]
```

### 6. 视觉属性
```python
"visual_attribute": [
    r"(?:红色|蓝色|绿色|黄色)\s*的\s*(.+)",         # 红色的按钮
    r"(?:大|小)\s*的\s*(.+)",                       # 大的图标
    r"(?:亮|暗)\s*的\s*(.+)",                       # 亮的区域
]
```

### 7. 等待条件
```python
"wait_condition": [
    r"等到\s*(.+?)\s*(?:出现|消失|完成)",           # 等到加载完成
    r"等待\s*(.+?)\s*(?:变化|更新)",                # 等待页面更新
    r"在\s*(\d+)\s*秒内\s*(.+)",                    # 在5秒内点击
]
```

### 8. 组合操作
```python
"combo": [
    r"按住\s*(.+?)\s*同时\s*(.+)",                  # 按住Shift同时点击
    r"先\s*(.+?)\s*然后\s*(.+)",                    # 先点击然后输入
    r"一边\s*(.+?)\s*一边\s*(.+)",                  # 一边滚动一边点击
]
```

### 9. 异常处理
```python
"error_handling": [
    r"如果\s*(?:失败|出错)[,，]?\s*就\s*(.+)",       # 如果失败就重试
    r"最多\s*(?:重试|尝试)\s*(\d+)\s*次",           # 最多重试3次
    r"(?:超时|超过)\s*(\d+)\s*秒\s*(.+)",           # 超过10秒就取消
]
```

### 10. 批量操作
```python
"batch": [
    r"(?:全选|选择全部)\s*(.+)",                    # 全选文件
    r"(?:批量|批量处理)\s*(.+)",                    # 批量删除
    r"(?:清空|删除所有)\s*(.+)",                    # 清空列表
]
```

## 🎯 核心问题

**正则表达式的本质局限：**

1. **无法理解语义**
   - "把价格降下来" - 无法理解"降下来"是操作还是状态
   - "准备好后点击" - 无法理解"准备好"的具体条件

2. **无法处理上下文**
   - "再点击一次" - 不知道"再"是指什么
   - "它旁边的按钮" - 不知道"它"指什么

3. **无法推理**
   - "找到最贵的商品" - 需要比较推理
   - "点击合适的位置" - 需要判断什么是"合适"

4. **无法处理歧义**
   - "点击右边的按钮" - 可能是多个按钮
   - "打开文件" - 可能是多个文件

## 💡 正确的方向

**规则 + AI 混合才是正解：**

```
简单操作（60%） → 规则匹配（快速、准确）
   ↓
中等操作（30%） → AI理解（智能、灵活）
   ↓
复杂操作（10%） → 人工确认（安全、可控）
```

**推荐架构：**

1. **第一层：规则匹配**（已实现）
   - 覆盖常见简单操作
   - 速度快、准确率高

2. **第二层：AI理解**（已实现）
   - 处理规则无法匹配的指令
   - 理解语义和上下文

3. **第三层：知识增强**（部分实现）
   - 软件特定操作模式
   - 常见任务模板

4. **第四层：交互确认**（未实现）
   - 歧义消除
   - 复杂流程确认
   - 学习用户意图
