## 📊 详细分析

### 问题1：缺少"打开应用"意图类型

**现状：**
- "打开记事本" 被误识别为 `menu` 意图
- 系统缺少 `open_app` 意图类型

**解决方案：**
```python
# 添加到 intent_patterns
"open_app": [
    r"打开\s*(.+)",
    r"启动\s*(.+)",
    r"运行\s*(.+)",
    r"开启\s*(.+)",
]
```

### 问题2：缺少"发送文件"意图类型

**现状：**
- "通过企业微信发送" 被误识别为 `menu` 意图
- 系统缺少 `send_file` 意图类型

**解决方案：**
```python
# 添加到 intent_patterns
"send_file": [
    r"(?:通过|用)\s*(.+?)\s*发送\s*(.+)",
    r"发送\s*(.+?)\s*给\s*(.+)",
    r"把\s*(.+?)\s*发送\s*(.+)",
]
```

### 问题3：多步骤任务识别能力不足

**现状：**
- 整体解析只识别出第一个匹配的模式
- 无法自动识别多步骤任务

**解决方案：**
```python
# 添加多步骤任务识别
"multi_step": [
    r"(.+?)\s*[,，]\s*(.+)",  # 逗号分隔
    r"(.+?)\s*然后\s*(.+)",   # 然后
    r"(.+?)\s*之后\s*(.+)",   # 之后
]
```
